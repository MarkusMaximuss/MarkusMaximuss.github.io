Git is a distributed version control system. The project was created by Linus Torvalds to manage Linux kernel development, with the first version released on April 7, 2005; coordinated by Jun Hamano.

Projects that use Git include the Linux kernel, Swift, Android, Drupal, Cairo, GNU Core Utilities, Mesa, Wine, Chromium, Compiz Fusion, FlightGear, jQuery, PHP, NASM, MediaWiki, DokuWiki, Qt, and a number of Linux distributions.

The program is free and released under the GNU GPL version 2. TCP port 9418 is used by default.

Git is the most widely used version control system and many people use it every day.
